# Sharing Notes for Recruiters / Hiring Managers

## One-line description

Applied B2B pricing experimentation workbench using public hotel-booking observations plus a transparent synthetic pricing-treatment layer to demonstrate experiment readout, incrementality, cannibalization, SQL/Python analytics and an AI-ready executive memo workflow.

## Why I built it

My professional background already includes pricing analytics, price harmonisation, value leakage detection, Power BI/Python/SQL-enabled decision tools and senior stakeholder decision support. I built this project to demonstrate how I would approach a marketplace-style pricing experimentation problem where controlled testing, incrementality and margin trade-offs matter.

## What to review first

1. Live Streamlit dashboard for the decision workflow and interactive scenario analysis.
2. `README.md` for business context, methodology and honest limitations.
3. `docs/executive_summary.md` for the pricing-manager decision flow.
4. `sql/experiment_readout.sql` for SQL logic using CTEs, conditional aggregation and window ranking.
5. `docs/methodology.md` for experiment-governance details.

## What this project should signal

- I understand pricing decisions are not only about revenue or volume.
- I can structure ambiguous commercial questions into eligibility, treatment/control logic, success metrics, guardrails and decision thresholds.
- I can use SQL/Python analytics to produce decision-ready evidence.
- I distinguish gross uplift from net incrementality and avoid double-counting cannibalization.
- I understand outcome leakage: cancellation is not used to select the experiment population.
- I can identify assumptions, guardrails and production limitations.
- I can use AI to accelerate executive communication while keeping analytical facts deterministic and human-reviewed.
- I am using a targeted project to close role-specific marketplace experimentation gaps transparently.

## What this project should not be interpreted as

This is not a claim that I have worked with proprietary marketplace pricing data or owned a production experimentation platform. It is an applied portfolio project demonstrating methodology, learning speed and practical decision support.

The public app does not call an LLM. It creates an AI-ready prompt pack from validated facts so the analytical and communication layers remain clearly separated.
