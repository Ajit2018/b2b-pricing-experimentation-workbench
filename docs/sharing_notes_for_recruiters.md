# Sharing Notes for Recruiters / Hiring Managers

## One-line description

Applied B2B pricing experimentation workbench using public hotel-booking data plus a transparent synthetic pricing-treatment layer to demonstrate experiment readout, incrementality, cannibalization, SQL/Python analytics and AI-assisted executive memo workflow.

## Why I built it

My professional background already includes pricing analytics, price harmonisation, value leakage detection, Power BI/Python/SQL-enabled decision tools and senior stakeholder decision support. I built this project to demonstrate how I would approach a marketplace-style pricing experimentation problem where controlled testing, incrementality and margin trade-offs matter.

## What to review first

1. `README.md` for business context and honest limitations.
2. Streamlit app if running locally.
3. `docs/executive_summary.md` for the business decision flow.
4. `sql/experiment_readout.sql` for SQL-style analytical logic.
5. `data/processed/hotel_pricing_experiment_panel.csv` for the processed panel.

## What this project should signal

- I understand pricing decisions are not only about revenue or volume.
- I can structure ambiguous commercial questions.
- I can use SQL/Python-style analytics to produce decision-ready evidence.
- I can identify guardrails and limitations.
- I can use AI to accelerate executive communication while keeping facts deterministic.
- I am using targeted projects to close role-specific gaps honestly.

## What this project should not be interpreted as

This is not a claim that I have worked with proprietary marketplace pricing data or owned a production experimentation platform. It is an applied portfolio project to demonstrate methodology, learning speed and practical decision support.
